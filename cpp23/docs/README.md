# C++23 Docs

This directory contains the C++23-facing documentation set.

- `MULTIPLICATION_WIDTHS.md` explains 1024-bit scalar multiply widths for 8, 16, 32, and 64-bit inputs.
- `SHIFT_BY_64.md` explains limb-aligned shifts and multiply-by-`2^(64*n)` cases.
- `BIOS_CMOS_OS.md` describes the firmware and OS stack.
- `FIRMWARE_API.md` describes the firmware control surface.
- `GUI_MODEL.md` describes the GUI state model.
