# Reference Index

This project does not have a public, canonical 1024-bit CPU/GPU CAD package to copy.
What does exist are usable reference designs, diagrams, RTL projects, and CAD tools.

## CPU and SoC references
- OpenTitan repository: https://github.com/lowRISC/opentitan
- OpenTitan docs: https://opentitan.org/book/
- CVA6 repository: https://github.com/openhwgroup/cva6
- CVA6 user manual: https://docs.openhwgroup.org/projects/cva6-user-manual/
- OpenRISC overview and OR1200 references: https://en.wikipedia.org/wiki/OpenRISC
- OR1200 overview: https://en.wikipedia.org/wiki/OpenRISC_1200

## GPU references
- Vortex repository: https://github.com/vortexgpgpu/vortex
- Vortex website: https://vortex.cc.gatech.edu/
- Vortex paper: https://arxiv.org/abs/2002.12151
- Vortex ISA and graphics extension paper: https://arxiv.org/abs/2110.10857

## CAD and layout tools
- KiCad: https://www.kicad.org/
- Open Cascade / OCCT: https://www.opencascade.com/

## Open hardware context
- OpenCores: https://en.wikipedia.org/wiki/OpenCores
- Open source hardware property survey: https://arxiv.org/abs/2412.08769

## 1024-scale references
- 1024 RV-core cluster: https://arxiv.org/abs/2408.08882
- Epiphany-V 1024-core SoC: https://arxiv.org/abs/1610.01832

These 1024-scale references are not 1024-bit datapaths, but they are useful when thinking about scaling, interconnects, and memory pressure.
