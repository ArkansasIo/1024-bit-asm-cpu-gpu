# System Gaps

This repository currently has:
- CPU ASM scaffold
- GPU ASM scaffold
- system-component notes
- module and type scaffolding
- external reference survey

It does not yet have:
- synthesizable RTL for the CPU
- synthesizable RTL for the GPU
- actual motherboard schematics
- PCB footprints
- package drawings
- enclosure CAD
- signal-integrity or power-integrity models

That is the main distinction between an architecture sketch and a hardware implementation.
